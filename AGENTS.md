# AGENTS.md — working on mailglow

For coding agents (Claude Code, Codex, Cursor, Gemini CLI, …) and humans contributing to this repo.
Using mailglow in *your* project is different: that is `skills/mailglow/SKILL.md`.

## Layout

```
skills/mailglow/SKILL.md          the skill agents load (workflow + rules)
skills/mailglow/scripts/mailglow.mjs   CLI: serve · lint · shoot · new · picks · rules · snap ·
                                       contract · fetch · render · stress · gallery · init
skills/mailglow/scripts/lib/      one module per concern (lint, mailbox, render, server, shoot,
                                  template, stress, gallery, install)
skills/mailglow/scripts/ui/       the inbox (one self-contained HTML file)
skills/mailglow/examples/         the templates; the gallery is built from here
tests/*.test.mjs                  node:test, no framework
site/                             generated by `gallery` — only site/config.json is tracked
```

## Commands

```bash
npm test                          # all tests (node --test); shoot/snap tests need Chrome/Chromium
bash scripts/validate-skills.sh   # SKILL.md frontmatter + marketplace manifest parity
bash scripts/check-private.sh     # no home paths, scratch paths, real e-mails (+ OCR with MAILGLOW_PRIVATE_TERMS)
npm run gallery                   # build site/ (use --no-shots without Chrome)
node skills/mailglow/scripts/mailglow.mjs lint skills/mailglow/examples
```

CI (`.github/workflows/ci.yml`) runs all of the above except the OCR half.

## Rules

- **Zero runtime dependencies.** Node ≥ 22 standard library only; Chrome is driven over CDP by hand.
  Don't add a `dependencies` entry — see `docs/adr/0001-zero-dependency-engine.md`.
- **Derive counts, never type them.** Rule and template counts come from `RULES` and the examples
  folder; the README badges are pinned by a test.
- **Examples lint 0/0**, hosted `https://` images only, fictional brands and people.
- **Nothing private.** No absolute paths from your machine, no real customer names, no real
  addresses — in code, docs *or screenshots*. Run `check-private.sh` with your denylist before you
  add or regenerate a PNG in `assets/`.
- **Look at what you ship.** A UI or gallery change is done when you've screenshotted it
  (`mailglow snap <url> --full`, desktop 1440 and mobile 390, light and dark) and opened the PNGs.
- **Tests with the change.** A new command or lint rule gets a test in `tests/`.
- Commits: conventional (`feat:`, `fix:`, `docs:`); add a line to `CHANGELOG.md` under *Unreleased*.
