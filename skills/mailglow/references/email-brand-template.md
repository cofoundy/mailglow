# EMAIL-BRAND.md template

Copy to the project root as `EMAIL-BRAND.md` and fill it with the user. Every email reads it.

```markdown
# Email brand — <Product>

## Sender
- From: <Product> <hello@product.com>          # a name people recognise, not noreply
- Reply-to: <support@product.com or none>
- App URL (links go here): https://app.product.com

## Logo (hosted — absolute https, answers 200)
- Light background: https://…/logo-dark-ink@2x.png   (display width: 120)
- Dark background:  https://…/logo-light-ink@2x.png  (or: same file, needs a background tile)

## Palette
| role       | light   | dark    |
|------------|---------|---------|
| page       | #f4f3f0 | #0f0f10 |
| card       | #ffffff | #1a1a1c |
| ink        | #1c1b19 | #f2f1ee |
| ink-2      | #57534e | #b9b6ae |
| ink-3      | #8c897f | #8c897f |
| rule       | #ecebe7 | #2c2b29 |
| accent     | #2f5bea | #7c9cff |
| accent-ink | #ffffff | #0d1330 |

## Type
- Sans: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif
- Serif (optional): Georgia, 'Times New Roman', serif
- Web font (Apple Mail only, optional): <url>

## Voice
- Is: <3 adjectives>
- Never says: <3 words or phrases>
- Language(s): <es-PE, en…>  · formality: <tú / usted / you>

## Footer
- Reason line: "You get this because …"
- Settings URL: https://app.product.com/settings/notifications
- Legal line: <Company · city / address>
```
